# 麦麦创贴 · 快乐，由你来贴

> 基于 **麦当劳中国 MCP（mcd-mcp）** 的个性化杯贴创作工具：在可口可乐杯 / 麦旋风 / McCafé / 薯条盒等 3D 容器上自由创作，并随时调用艺术家预置贴纸提质，把表达欲织进一条**纯前端、零后端**的虚拟创作链路。

本仓库为「麦当劳程序员创意开发大赛」参赛项目。

🌐 **在线演示（GitHub Pages）**：https://jzcreative.github.io/mcd-cuptez/

---

## 一、项目简介

「麦麦创贴」把茶饮品牌流行的「手绘杯贴」玩法，合理迁移到麦当劳更丰富的包装载体上：

- **用户自由创作为主**：开屏即空白 3D 容器，画笔 / 文字 / 形状完全由用户掌控，不预设任何模板。
- **艺术家贴纸随时调用**：内置透明贴纸资产（线条童趣 / 波普 / 极简几何 / 星夜线等风格），点击即叠加、可拖动、可撤除——**调用时机完全由用户决定**，不用时就是纯手绘。
- **官方主题内置 / 可选 MCP 增强**：当期活动主题（`campaign-calendar`）可经可选代理自动注入「官方主题」贴纸包；页面本身零后端，离线即可完整体验。

与喜茶杯贴的本质区别：**你随便画，但随时能一键调用艺术家贴纸来提质**——自由是默认，资产是加成。

## 二、核心特性

| 特性 | 说明 |
|---|---|
| 3D 容器画布 | 四款容器（可乐杯 / 麦旋风 / McCafé / 薯条盒）真实 3D 模型，支持旋转、移动、缩放 |
| 自由创作 | 画笔（多色）、文字（点哪写哪）、橡皮点删、撤销、清空 |
| 艺术家预置资产 | 多风格透明贴纸包，随时叠加 / 移除 / 拖动 |
| 当期主题 | 内置虚拟当期活动（联名季风格），可选接入 `campaign-calendar` 实时增强 |
| 双格式导出 | 导出当前视角 PNG（2× 栅格）/ 正面设计矢量源（SVG） |
| 订单备注（本地） | 备注在本机生成与保存，不依赖任何后端；可配置代理后升级为真实下单 |
| 单文件离线 | 主程序 `mcd-cuptez.html` 自包含（three.js / GLTFLoader / DRACO 全内联），无需联网、无需构建 |

## 四、安装与运行

### 方式 A：直接打开（推荐，纯前端零后端）

`mcd-cuptez.html` 为自包含单文件，双击或用浏览器打开即可，**无需 Node、无需联网、无需构建、无需任何后端**。当期主题与官方贴纸已内置，开箱即完整体验；创作、导出、订单备注保存全部在本机完成。

### 方式 B：GitHub Pages 在线演示

- **在线地址**：https://jzcreative.github.io/mcd-cuptez/
- 由 GitHub Pages 静态托管，完整 UI、3D 容器、自由创作、艺术家贴纸与导出均可用，完全离线可跑、**不依赖任何服务端**。

### 方式 C：本地代理运行（**可选 / 进阶，用于真实接入麦当劳 MCP**）

> 仅当你希望页面拉取真实的当期活动或发起真实订单时才需要。页面本身已内置虚拟当期活动，无代理也能完整体验。

```bash
# 在仓库目录下执行（需能访问 mcp.mcd.cn，且本机 ~/.workbuddy/mcp.json 含 Token，或设了 MCD_MCP_TOKEN）
python3 mcp-proxy.py
# 浏览器打开 http://127.0.0.1:8787
```

代理会托管页面并把同源 `/mcp` 请求转发到 `https://mcp.mcd.cn`，**Token 由服务端注入，不进入客户端代码**。加载即真实拉取当期活动并注入官方主题贴纸。可用环境变量 `MCP_PROXY_PORT` 改端口、`MCD_MCP_TOKEN` 显式指定 Token。

## 五、配置麦当劳 MCP（可选 / 进阶）

1. 前往 `open.mcd.cn/mcp` 用手机号登录并申请 **MCP Token**。
2. 本原型通过 `mcp-proxy.py` 读取 Token：默认从 `~/.workbuddy/mcp.json` 的 `mcd-mcp.headers.Authorization` 读取，也可用环境变量 `MCD_MCP_TOKEN` 显式指定。**Token 仅留在本机，不进入任何仓库文件。**
3. 运行 `python3 mcp-proxy.py` 后打开 `http://127.0.0.1:8787`，应用内即尝试真实调用 `campaign-calendar` / `now-time-info` 并注入官方主题；若未运行代理，页面直接使用内置虚拟当期活动，体验不受影响。

> 详情见 [`MCP_INTEGRATION.md`](./MCP_INTEGRATION.md) 与 [`mcd-mcp-dev-rules.md`](./mcd-mcp-dev-rules.md)。

## 六、使用示例

1. 打开 `mcd-cuptez.html`，默认进入「可乐杯」空白 3D 画布。
2. 横滑切换杯型（麦旋风 / McCafé / 薯条盒）。
3. 用画笔自由涂鸦，或用文字工具写下口号。
4. 点底部「贴纸」唤起抽屉，点一张艺术家贴纸——想提质时点，不想用就纯手绘。
5. 点「导出图」：保存当前视角 PNG 与正面设计 SVG。
6. （可选）点「写订单备注」，生成可复制的备注并保存到本机；若已配置 MCP 代理，可进一步升级为真实下单。
