关于在线版：本页面由 GitHub Pages 静态托管，完整 UI、3D 容器、自由创作、艺术家贴纸与导出均可用；但因 Pages 无法运行本地 MCP 代理，当期活动官方贴纸包以静态占位呈现，创作与导出功能不受影响。
如需真实联动麦当劳 MCP 数据（当期活动自动注入、订单备注闭环），请按仓库 README「方式 B」在本机运行 mcp-proxy.py。
